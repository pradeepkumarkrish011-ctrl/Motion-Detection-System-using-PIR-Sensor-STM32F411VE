# Motion-Detection-System-using-PIR-Sensor-STM32F411VE
PIR-based motion detection system using STM32F411VE and STM32CubeIDE. Detects human motion with the HC-SR501 sensor and activates an LED and buzzer. Uses USART2 UART communication to display real-time motion status on Tera Term. Implements GPIO configuration, sensor interfacing, and Embedded C programming.
